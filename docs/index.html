Profile

I am a full-stack PHP developer in Budapest. I build web applications with Symfony on the server and Angular and TypeScript in the browser, and I follow the work down into PostgreSQL, where I write triggers and stored procedures and help design the schema underneath them.

For more than three years I coordinated the development of a web platform in a GitLab CI/CD and RHEL environment: I organised the internal testing of what the external team delivered, and built the platform’s support site on my own.

I came to development by way of testing. I started in IT in 2008 with data preparation and VBA, then spent several years as a software tester, writing automated tests in Selenium WebDriver and running user acceptance and exploratory testing. Since then I have refactored legacy PHP, built applications in Laravel and CodeIgniter, and for a few years looked after WordPress: a multisite of more than 200 sites, with themes I built for it.

Projects

Work and personal projects, each with a few lines on what it is for.

  • Fuzzphony

    My open-source search library for PHP and Symfony, built on PostgreSQL alone. It adds ranked full-text search that tolerates typos and ignores accents, with filters and a query language, and needs no Elasticsearch, Meilisearch or other external service. Existing tables stay as they are: the index lives in a separate table beside them. Built in an AI-agent-assisted workflow; mutation testing keeps its quality in check.

    Tags: PHPSymfonyPostgreSQLMutation testing

    See it on GitHub · Fuzzphony (opens in a new tab)

  • Slimfony

    An ultra-lightweight core for PHP microservices in FrankenPHP worker mode, built from a few Symfony components. The container and the routes are compiled at build time, and nothing is kept between requests. Secure by default: no error details leak out, and with authentication on (JWT), everything is denied until the caller is verified. PostgreSQL access is safe in a long-lived worker, and Prometheus metrics and health checks are built in.

    Tags: PHPSymfonyFrankenPHPPostgreSQLPrometheus

    See it on GitHub · Slimfony (opens in a new tab)
